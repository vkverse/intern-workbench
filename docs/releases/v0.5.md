# v0.5.0 public preview

## Release acceptance scope

- A single entry page routes interns, mentors and contributors.
- Fork-first onboarding explains remotes, local identity, first submission, PR review, and sync.
- Username-separated folders prevent different interns from overwriting the same task artifact.
- 18 active task specifications have concrete requirements and exercise contracts.
- 188 retained outlines are explicitly draft; all 206 permanent IDs are preserved.
- Six function/HTTP exercises provide contract tests; debugging and review fixtures are intentionally flawed.
- Framework validation checks metadata, dependencies/cycles, required content, active contracts, file links and catalogue consistency.
- Regression tests cover invalid metadata, Windows line endings, prerequisite errors, helper path safety, starter failures, and valid reference solutions.
- CI runs on Linux and Windows with supported Node versions and read-only repository permissions.

## Version correction

The initial scaffold declared 1.0.0 before its curriculum was complete. This release deliberately corrects that premature version to 0.5.0 public preview. It is not a semantic claim that a stable v1 was delivered and then downgraded. No earlier release tags are rewritten.

## Verification boundaries

Local verification on Windows with Node 22.21.0 (2026-09-07):

- `npm ci`: successful, no runtime or development packages required.
- `npm run validate`: 206 IDs validated, 18 active and 188 draft.
- `npm test`: 37 tests passed, zero failures or skips.
- CLI integration prepares all 18 active tasks, rejects empty evidence, preserves existing work, and catches broken function/HTML/test submissions.
- Six exercise reference implementations pass; all six unfinished starters fail their contracts.
- `npm run check:submissions`: successful with zero committed v0.5 learner submissions; synthetic integration fixtures are not learner evidence.

The Linux/Windows and Node 22/24 matrix must pass in the implementation PR before merge.

Automated local tests and GitHub CI results are reported with the implementation PR. The prior two-account sessions demonstrated fork/push/review/merge mechanics and used AI assistance. No unassisted fresh-intern cohort, full curriculum walkthrough, performance benchmark, or mentor-time reduction study has been completed.

Browser accessibility and visual criteria still require manual evidence. The framework validator does not fetch external links, check Markdown anchors, judge prose, or certify security. Reference solutions under tests are maintainer checks, not hidden anti-cheating infrastructure.

## Deferred

React/Next.js applications, PostgreSQL/authentication environments, full-stack capstone implementation, and advanced production-incident labs remain draft. Promote them only with specific contracts, working starters, tests, and review.

No SaaS, LMS, hosted dashboard, billing, custom authentication platform, or AI detector is part of this release.
