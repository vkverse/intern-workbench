# GIT-009 exercise contract

Deliver a small change through a fork pull request.

1. Confirm origin points to your fork and upstream to the mentor repository.
2. Use this task branch to add a 100-word explanation of fork, clone, commit, push, and pull request in README.md.
3. Open a PR targeting the mentor main branch, link the assigned issue, and include actual check results and AI disclosure.

## Completion evidence

- PR head is your fork and base is the mentor repository.
- The Issue number is distinct from GIT-009.
- Review feedback is answered on the same branch, not through a replacement PR.

## Start and check

From the repository root, replace octocat with your username:

    npm run workbench -- start GIT-009 octocat
    npm run workbench -- check GIT-009 octocat

The starter is intentionally incomplete. README section checks only confirm evidence is present; a mentor evaluates its truth and quality. Copy-safe username examples are for explanation, not automatic identity detection.
