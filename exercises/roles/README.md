# ORI-001 exercise contract

Explain who owns a password-reset feature.

1. Write a 150-300 word note assigning responsibility to product, design, frontend, backend, QA, and mentor.
2. Trace one password-reset request from user need to release; explain where clarification and review happen.
3. Describe what happens when a reset email is delayed and who investigates; distinguish a task ID from an Issue number.

## Completion evidence

- Every role has a concrete deliverable, not just a job title.
- The workflow includes testing, review, and maintenance.
- The delayed-email example identifies a next diagnostic step without blaming a person.

## Start and check

From the repository root, replace octocat with your username:

    npm run workbench -- start ORI-001 octocat
    npm run workbench -- check ORI-001 octocat

The starter is intentionally incomplete. README section checks only confirm evidence is present; a mentor evaluates its truth and quality. Copy-safe username examples are for explanation, not automatic identity detection.
