# ORI-006 exercise contract

Verify your machine can run this repository.

1. Record OS, git --version, node --version, and npm --version in README.md; use Node 22 or 24.
2. Run npm ci and npm run validate from the repository root and record the actual outcome.
3. Explain your current working directory, a relative path, and why node_modules is not committed.

## Completion evidence

- Tool versions and actual command outcomes are recorded.
- An access/setup failure includes the exact error and attempted diagnostic, with sensitive data removed.
- No machine username, token, or absolute home directory is required as evidence.

## Start and check

From the repository root, replace octocat with your username:

    npm run workbench -- start ORI-006 octocat
    npm run workbench -- check ORI-006 octocat

The starter is intentionally incomplete. README section checks only confirm evidence is present; a mentor evaluates its truth and quality. Copy-safe username examples are for explanation, not automatic identity detection.
