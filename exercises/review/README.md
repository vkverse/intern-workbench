# REVIEW-005 exercise contract

Review a flawed cart implementation without changing it.

1. Read exercises/review/fixture.mjs and its contract. Write three comments in README.md with file/line, reproducible input, expected/actual output, and impact.
2. Distinguish a correctness blocker from a suggestion; propose a test for each blocker.
3. Include one respectful question about rounding or validation requirements instead of assuming product policy.

## Completion evidence

- Comments identify defects using concrete evidence.
- The review does not replace the implementation.
- Tone addresses the code and requirement rather than the author.

## Start and check

From the repository root, replace octocat with your username:

    npm run workbench -- start REVIEW-005 octocat
    npm run workbench -- check REVIEW-005 octocat

The starter is intentionally incomplete. README section checks only confirm evidence is present; a mentor evaluates its truth and quality. Copy-safe username examples are for explanation, not automatic identity detection.
