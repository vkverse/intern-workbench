# HTML-001 exercise contract

Build a semantic community profile page.

1. Create index.html with a doctype, html lang, UTF-8 charset, viewport, and descriptive title.
2. Add one h1, a header, nav, main, two titled sections, and footer. Use a fictional profile with About and Contact links targeting real section IDs.
3. Open the page in a browser; navigate every link using only the keyboard.

## Completion evidence

- Document landmarks and heading hierarchy match the content.
- Every in-page link reaches an existing section.
- No personal contact data or external service is required.

## Start and check

From the repository root, replace octocat with your username:

    npm run workbench -- start HTML-001 octocat
    npm run workbench -- check HTML-001 octocat

The starter is intentionally incomplete. README section checks only confirm evidence is present; a mentor evaluates its truth and quality. Copy-safe username examples are for explanation, not automatic identity detection.
