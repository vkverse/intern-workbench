# Start here

You only need the instructions for your role.

| Your role | Open next | What you will do |
|---|---|---|
| Intern | [Onboarding](ONBOARDING.md) | Find your assigned task, prepare your folder, submit a PR |
| Mentor/company | [Mentor guide](MENTOR-GUIDE.md) | Create a training copy, choose tasks, agree policies, review evidence |
| Framework contributor | [Contributing](CONTRIBUTING.md) | Improve the framework through a focused PR |

## First week

Use the [starter route](tracks/starter.md). An active task is ready for a supervised pilot; draft outlines should not be assigned without company authorship and review.

## Where things live

- curriculum: task specifications; read only your assigned task.
- exercises: contracts and starter code shared by all interns.
- submissions/YOUR-USERNAME/TASK-ID: your implementation and evidence.
- company: the adopting team's configuration.
- docs: optional reference material, release notes, and mentor evaluation.
- projects: longer-term project briefs; see their readiness notice.

Do not start by reading every Markdown file.
