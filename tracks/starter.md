# v0.5 starter route

These 18 tasks are a supervised pilot, not a full-stack career certification. Pick a pace from actual evidence; do not force all work into one week.

| Stage | Tasks | Outcome |
|---|---|---|
| First sessions | ORI-001 → ORI-006 → GIT-003 → GIT-009 | Environment evidence, staging experiment, reviewed PR practice |
| Git practice | GIT-006 after GIT-003 | Conflict reproduction and documented resolution |
| Browser path | HTML-001 → HTML-004 → HTML-008; CSS-007 after HTML-001 | Semantic page, accessible form, audit, responsive layout |
| JavaScript path | JS-004 → JS-010 → NODE-003 | Data transformation, injected fetch, working HTTP API |
| Test and diagnose | TEST-002 and DEBUG-004 after JS-004 | Behavior tests and a reproduced/fixed cart bug |
| Security and review | SEC-006 after GIT-003 and JS-004; REVIEW-005 after DEBUG-004 | Redaction exercise and evidence-backed code review |
| Communicate and plan | DOCS-001 after NODE-003; FINAL-001 after CSS-007, NODE-003, TEST-002 | Reproducible runbook and scoped capstone plan |

Look up task links, estimates and prerequisites in [CURRICULUM.md](../CURRICULUM.md). Run npm run workbench -- list for active IDs.

Each task has its own username-isolated directory. HTML audit explicitly copies the learner's earlier form; other tasks do not assume unprovided project code. Prerequisites form branches, not a mandatory 206-task chain.

Four-week pilot suggestion: week 1 onboarding/Git/browser; week 2 browser/JS; week 3 API/tests/debugging; week 4 security/review/docs/capstone plan. Adjust for experience and review capacity. Longer 8/12/16-week curricula require company work or completing draft tracks.
