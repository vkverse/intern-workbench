# Intern submissions

Run `npm run workbench -- start ORI-001 YOUR-USERNAME` from the repository root.
Each intern owns `submissions/<github-username>/<TASK-ID>/`.
Do not edit another intern's folder or shared exercise contracts in an assignment PR.
The generated README needs actual outcomes, evidence, reflection, and honest AI disclosure.
See [onboarding](../ONBOARDING.md). Starter failures are expected until you implement the task.
